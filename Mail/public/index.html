PiSigma Mail

Shared transactional email for PiSigma / PlexApps — SMTP-backed product. No Resend. Admin via token or pisigma-auth (not Clerk).

Send

curl -X POST "$MAIL_URL/v1/send" \
  -H "Authorization: Bearer pm_live_…" \
  -H "Idempotency-Key: sub_123" \
  -H "Content-Type: application/json" \
  -d '{"to":"you@example.com","subject":"Hi","text":"Hello"}'
