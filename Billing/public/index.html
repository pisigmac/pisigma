PiSigma Billing

Shared Razorpay billing spine for PiSigma / PlexApps products — products call Billing with API keys; Razorpay secrets stay here.

  • /health
  • /v1/openapi.json
  • POST /v1/orders with Authorization: Bearer pb_live_…
  • POST /v1/verify — HMAC payment signature
  • Webhook: POST /v1/webhooks/razorpay
  • Admin: X-Admin-Token on /v1/admin/*

Create order

curl -X POST "$BILLING_URL/v1/orders" \
  -H "Authorization: Bearer pb_live_…" \
  -H "Idempotency-Key: ord_123" \
  -H "Content-Type: application/json" \
  -d '{"plan":"pro"}'
